# 测试依赖

本包测试**默认零第三方依赖**：JSON Schema 校验由包内 `tests/schema_lite.py`
（Draft 2020-12 子集）提供，不需要 `jsonschema`。

## 必需

- Python 3.10+
- `Pillow`（读写/校验夹具图片）
  ```bash
  python -m pip install Pillow
  ```

## 可选

- `jsonschema>=4.20`（若要额外用官方实现交叉校验契约；**可选**，缺失时本包测试仍全绿）
- `python-docx>=1.1`（仅用于生成 `review/` 下的 Word 审阅说明，不参与契约校验）

## 运行

```bash
python tests/validate_example_contracts.py    # 正例 + 负例（24 项）
python tests/test_negative_fixtures.py        # 仅负例（10 组）
python tests/mock_provider.py --selftest      # Provider 错误映射与预算（19 项）
python tests/build_direction_docs.py          # 由 registry 重新生成方向规则正文
python tests/create_examples.py               # 重新生成全部夹具（会覆盖 examples/）
python tests/build_review_notes.py            # 重建 review/*.docx（需 python-docx）
```
