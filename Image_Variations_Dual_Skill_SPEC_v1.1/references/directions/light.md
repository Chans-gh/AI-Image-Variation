# 方向规则：光影拓展（`light`）

**规则版本**：1.0　|　**注册表版本**：1.0　|　**状态**：`active`　|　**支持模式**：grid、sequence
**默认分支**：`variants`（离散变体）　|　**可选分支**：`variants`（离散变体）、`progression`（渐进演变）、`narrative`（情节叙事）

> 本文件由 `tests/build_direction_docs.py` 从 `registry.json` 生成，请勿手改；规则变更改注册表后重跑脚本。

## 允许变化（allowed_changes）

- 光源方向：正面、侧面、逆光、顶光、底光
- 光质：硬光与柔光、散射与直射
- 色温与色彩倾向：暖调、冷调、混合光
- 明暗对比与阴影长度、投影形状
- 时段光线氛围：清晨、正午、黄昏、夜景

## 必须保持（must_preserve）

- 主体形态与身份
- 动作与姿态（同一任务内不靠动作制造差异）
- 场景结构与陈设位置
- 主构图与画幅

## 禁止项（avoid）

- 通过更换场景来制造光差
- 把主体改色当作光影变化
- 出现与设定时段矛盾的天空/环境光

## 变化示例（variation_examples）

- 同一只浅灰陶杯：清晨侧光、正午顶光、黄昏低角度逆光、夜间台灯暖光
- 同一张人像：窗光柔光、硬光侧打、轮廓逆光、混合霓虹
- 同一束花：日光、阴天散射、烛光、冷调 LED

## Grid 规则

- 行优先映射：是
- 零间距零边框：是
- Grid 不表达时间/因果顺序：是
- 格位提示：每格一个独立光照方案，避免格子之间仅亮度微调

## Sequence 规则

- 张数范围：4–16 张
- 渐进轴提示：一天内的时间光轴或明暗对比强度轴
- 叙事分支需要世界观上下文：否

## 与其他方向的边界

- 本方向只改变上表「允许变化」中的元素；出现 `must_preserve` 被改动，或落入 `avoid`，即判为该张不通过。
- 一个任务只能选择一个方向。若用户表达同时命中两个方向（例如"换场景同时换天气"），先请用户确认优先级，不自动混用。
- 主体一致性由 SPEC 01 §6 的锚点规则统一保证，本文件不重复定义锚点。
