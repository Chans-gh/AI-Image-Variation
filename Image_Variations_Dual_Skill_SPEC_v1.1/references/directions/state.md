# 方向规则：状态拓展（`state`）

**规则版本**：1.0　|　**注册表版本**：1.0　|　**状态**：`active`　|　**支持模式**：grid、sequence
**默认分支**：`variants`（离散变体）　|　**可选分支**：`variants`（离散变体）、`progression`（渐进演变）、`narrative`（情节叙事）

> 本文件由 `tests/build_direction_docs.py` 从 `registry.json` 生成，请勿手改；规则变更改注册表后重跑脚本。

## 允许变化（allowed_changes）

- 动作阶段：静态摆放 → 拿起 → 使用中 → 收纳
- 姿态与朝向：坐、立、倾身、转身、低头
- 表情与情绪强度：平静、专注、愉悦、疲惫
- 操作状态：关闭、启动中、满载、维护中
- 与手部/工具的交互状态

## 必须保持（must_preserve）

- 主体身份与可识别特征（人脸、轮廓、标志性结构）
- 默认造型与服饰（除非用户另行选择 styling 方向）
- 场景主题与空间逻辑
- 光影基调和整体画面风格

## 禁止项（avoid）

- 改变主体身份或年龄感
- 同时更换场景或服装（那属于 scene / styling）
- 引入画外人物或新道具抢夺主体

## 变化示例（variation_examples）

- 同一只马克杯：空置、注入咖啡、被人端起、放在沥水架上
- 同一只猫：蜷睡、伸懒腰、盯向镜头、跃下窗台
- 同一台相机：收纳在包中、握持准备、举至眼前、放回桌面

## Grid 规则

- 行优先映射：是
- 零间距零边框：是
- Grid 不表达时间/因果顺序：是
- 格位提示：每个格位一个独立状态，格间不构成因果或时间顺序

## Sequence 规则

- 张数范围：4–16 张
- 渐进轴提示：动作完成度或情绪强度轴
- 叙事分支需要世界观上下文：否

## 与其他方向的边界

- 本方向只改变上表「允许变化」中的元素；出现 `must_preserve` 被改动，或落入 `avoid`，即判为该张不通过。
- 一个任务只能选择一个方向。若用户表达同时命中两个方向（例如"换场景同时换天气"），先请用户确认优先级，不自动混用。
- 主体一致性由 SPEC 01 §6 的锚点规则统一保证，本文件不重复定义锚点。
