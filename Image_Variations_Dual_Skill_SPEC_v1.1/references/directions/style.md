# 方向规则：风格拓展（`style`）

**规则版本**：1.0　|　**注册表版本**：1.0　|　**状态**：`active`　|　**支持模式**：grid、sequence
**默认分支**：`variants`（离散变体）　|　**可选分支**：`variants`（离散变体）、`progression`（渐进演变）、`narrative`（情节叙事）

> 本文件由 `tests/build_direction_docs.py` 从 `registry.json` 生成，请勿手改；规则变更改注册表后重跑脚本。

## 允许变化（allowed_changes）

- 媒介与技法：写实摄影、电影感、水彩、油画、矢量插画、3D 渲染、拼贴
- 艺术流派与年代感：印象派、极简、复古胶片、赛博朋克
- 材质与质感表达：笔触、颗粒、纸感、金属反射
- 色彩体系与调色风格
- 光线的艺术化处理方式

## 必须保持（must_preserve）

- 主体身份与核心结构
- 主体内容与世界观设定
- 主体与场景的基本关系
- 画面中的关键物件数量与位置逻辑

## 禁止项（avoid）

- 在换风格时改变主体身份或物种
- 风格之间无过渡地跳跃（progression 分支下尤其禁止）
- 声称还原某位在世艺术家的独特风格以规避版权风险

## 变化示例（variation_examples）

- 同一只猫：写实摄影、水彩插画、低多边形 3D、黑白版画
- 同一座小屋：油画、线稿、胶片摄影、像素艺术
- 同一束花：柔焦摄影、油画厚涂、纸雕、矢量扁平

## Grid 规则

- 行优先映射：是
- 零间距零边框：是
- Grid 不表达时间/因果顺序：是
- 格位提示：每格一种独立风格；同一格位内不混搭两种风格

## Sequence 规则

- 张数范围：4–16 张
- 渐进轴提示：由写实逐步过渡到风格化（如 0%→100% 插画化）
- 叙事分支需要世界观上下文：否

## 与其他方向的边界

- 本方向只改变上表「允许变化」中的元素；出现 `must_preserve` 被改动，或落入 `avoid`，即判为该张不通过。
- 一个任务只能选择一个方向。若用户表达同时命中两个方向（例如"换场景同时换天气"），先请用户确认优先级，不自动混用。
- 主体一致性由 SPEC 01 §6 的锚点规则统一保证，本文件不重复定义锚点。
