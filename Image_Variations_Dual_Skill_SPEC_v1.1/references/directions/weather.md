# 方向规则：时间天气拓展（`weather`）

**规则版本**：1.0　|　**注册表版本**：1.0　|　**状态**：`active`　|　**支持模式**：grid、sequence
**默认分支**：`progression`（渐进演变）　|　**可选分支**：`variants`（离散变体）、`progression`（渐进演变）、`narrative`（情节叙事）

> 本文件由 `tests/build_direction_docs.py` 从 `registry.json` 生成，请勿手改；规则变更改注册表后重跑脚本。

## 允许变化（allowed_changes）

- 天气：晴、阴、雨、雪、雾、风
- 季节：春、夏、秋、冬及其环境线索
- 一天中的时段与光线倾向
- 空气感：湿度、尘埃、光斑、雨雪颗粒
- 天气导致的二次效果：水洼、积雪、落叶、雾气扩散

## 必须保持（must_preserve）

- 主体身份与形态
- 场景地点逻辑（不能晴天在室内突然下雪）
- 世界观与整体画面质感
- 主体与环境的物理关系合理

## 禁止项（avoid）

- 把天气变化做成场景更换（地点必须保持可辨识）
- 出现与季节矛盾的植被或服装（除非用户明确要求）
- 天气特效遮挡主体关键结构

## 变化示例（variation_examples）

- 同一扇窗：清晨薄雾、正午晴光、黄昏阵雨、夜间落雪
- 同一条街道：春日晴、梅雨、秋日落叶、冬日积雪
- 同一把伞：晴日遮阳、细雨、暴雨、雪天

## Grid 规则

- 行优先映射：是
- 零间距零边框：是
- Grid 不表达时间/因果顺序：是
- 格位提示：每格一种天气/时段，格间不构成时间顺序

## Sequence 规则

- 张数范围：4–16 张
- 渐进轴提示：同一场景的天气演进（如晴 → 多云 → 雨 → 雨后）或四季轮转
- 叙事分支需要世界观上下文：否

## 与其他方向的边界

- 本方向只改变上表「允许变化」中的元素；出现 `must_preserve` 被改动，或落入 `avoid`，即判为该张不通过。
- 一个任务只能选择一个方向。若用户表达同时命中两个方向（例如"换场景同时换天气"），先请用户确认优先级，不自动混用。
- 主体一致性由 SPEC 01 §6 的锚点规则统一保证，本文件不重复定义锚点。
