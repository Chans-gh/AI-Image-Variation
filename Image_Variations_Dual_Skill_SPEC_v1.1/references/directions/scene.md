# 方向规则：场景拓展（`scene`）

**规则版本**：1.0　|　**注册表版本**：1.0　|　**状态**：`active`　|　**支持模式**：grid、sequence
**默认分支**：`variants`（离散变体）　|　**可选分支**：`variants`（离散变体）、`progression`（渐进演变）、`narrative`（情节叙事）

> 本文件由 `tests/build_direction_docs.py` 从 `registry.json` 生成，请勿手改；规则变更改注册表后重跑脚本。

## 允许变化（allowed_changes）

- 地点与环境：室内/室外、城市/自然、工作室/居家
- 道具与陈设组合
- 使用情境与背景故事暗示
- 空间尺度与材质环境
- 背景色彩基调（在不改变主体本身的前提下）

## 必须保持（must_preserve）

- 主体核心外形与身份
- 视觉风格与镜头语言
- 主体与环境的尺度关系合理
- 画面整体品质与光线质量

## 禁止项（avoid）

- 改变主体外观（那属于 styling / style）
- 让主体在部分格位中缺失或不可辨认
- 场景之间出现品牌侵权或真实地点宣称

## 变化示例（variation_examples）

- 同一只背包：地铁通勤、山野徒步、咖啡馆、机场候机
- 同一盆绿植：阳台、办公桌、浴室窗台、庭院
- 同一支钢笔：会议桌、稿纸、书店、旅行日记

## Grid 规则

- 行优先映射：是
- 零间距零边框：是
- Grid 不表达时间/因果顺序：是
- 格位提示：每格一个独立场景，互不构成时间线

## Sequence 规则

- 张数范围：4–16 张
- 渐进轴提示：空间迁移（由近及远/由室内到室外）
- 叙事分支需要世界观上下文：否

## 与其他方向的边界

- 本方向只改变上表「允许变化」中的元素；出现 `must_preserve` 被改动，或落入 `avoid`，即判为该张不通过。
- 一个任务只能选择一个方向。若用户表达同时命中两个方向（例如"换场景同时换天气"），先请用户确认优先级，不自动混用。
- 主体一致性由 SPEC 01 §6 的锚点规则统一保证，本文件不重复定义锚点。
