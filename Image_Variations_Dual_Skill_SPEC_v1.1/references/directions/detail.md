# 方向规则：细节拓展（`detail`）

**规则版本**：1.0　|　**注册表版本**：1.0　|　**状态**：`active`　|　**支持模式**：grid、sequence
**默认分支**：`progression`（渐进演变）　|　**可选分支**：`variants`（离散变体）、`progression`（渐进演变）、`narrative`（情节叙事）

> 本文件由 `tests/build_direction_docs.py` 从 `registry.json` 生成，请勿手改；规则变更改注册表后重跑脚本。

## 允许变化（allowed_changes）

- 整体与局部的切换：全貌、半身、局部特写、微距
- 工艺与材质细节：纹理、缝线、铆接、釉面
- 关键部件与结构剖面
- 微观元素：颗粒、纤维、水珠、磨损痕迹
- 光线落在材质表面形成的细节特征

## 必须保持（must_preserve）

- 同一来源主体（必须是同一件物品/同一人物）
- 材质逻辑一致（不能陶瓷变金属）
- 色彩与美术体系一致
- 拍摄风格一致

## 禁止项（avoid）

- 把不同物体的局部混入同一组
- 细节与整体描述矛盾
- 为追求细节而改变主体配色方案

## 变化示例（variation_examples）

- 同一只陶杯：整体、杯口釉面、把手接缝、底部款识
- 同一件毛衣：整体廓形、针织纹理、袖口收边、纽扣特写
- 同一只手表：整体、表盘、表冠、表带链节

## Grid 规则

- 行优先映射：是
- 零间距零边框：是
- Grid 不表达时间/因果顺序：是
- 格位提示：格位可跨尺度，但每格必须是同一来源的真实局部

## Sequence 规则

- 张数范围：4–16 张
- 渐进轴提示：焦距/尺度渐进：整体 → 中景 → 局部 → 微距
- 叙事分支需要世界观上下文：否

## 与其他方向的边界

- 本方向只改变上表「允许变化」中的元素；出现 `must_preserve` 被改动，或落入 `avoid`，即判为该张不通过。
- 一个任务只能选择一个方向。若用户表达同时命中两个方向（例如"换场景同时换天气"），先请用户确认优先级，不自动混用。
- 主体一致性由 SPEC 01 §6 的锚点规则统一保证，本文件不重复定义锚点。
