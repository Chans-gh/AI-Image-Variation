# 方向规则：情节拓展（`narrative`）

**规则版本**：1.0　|　**注册表版本**：1.0　|　**状态**：`active`　|　**支持模式**：grid、sequence
**默认分支**：`narrative`（情节叙事）　|　**可选分支**：`variants`（离散变体）、`progression`（渐进演变）、`narrative`（情节叙事）

> 本文件由 `tests/build_direction_docs.py` 从 `registry.json` 生成，请勿手改；规则变更改注册表后重跑脚本。

## 允许变化（allowed_changes）

- 故事节点：起因、发展、转折、结果
- 人物/物品之间的互动关系
- 事件阶段与环境响应变化
- 情绪弧线
- 同一世界观内的场景切换

## 必须保持（must_preserve）

- 核心角色/物品身份与外观
- 世界观设定与美术基调
- 造型连续性与年代设定
- 空间关系的可解释性

## 禁止项（avoid）

- 每张图另起一个无关故事
- 补造未展示的关键情节事实并对外宣称真实事件
- 角色形象前后不一致

## 变化示例（variation_examples）

- 同一只猫的一天：清晨窗台、午后追逐、黄昏等待、夜里蜷睡
- 同一趟旅程：出发准备、途中风景、目的地抵达、返程
- 同一支笔的使用故事：落笔、书写、修改、签下名字

## Grid 规则

- 行优先映射：是
- 零间距零边框：是
- Grid 不表达时间/因果顺序：是
- 格位提示：Grid 下不承诺时间顺序，只呈现同一世界的多个片段；不得暗示连续因果

## Sequence 规则

- 张数范围：4–16 张
- 渐进轴提示：情节阶段轴：起因 → 发展 → 转折 → 结果（按 N 扩展）
- 叙事分支需要世界观上下文：是

## 与其他方向的边界

- 本方向只改变上表「允许变化」中的元素；出现 `must_preserve` 被改动，或落入 `avoid`，即判为该张不通过。
- 一个任务只能选择一个方向。若用户表达同时命中两个方向（例如"换场景同时换天气"），先请用户确认优先级，不自动混用。
- 主体一致性由 SPEC 01 §6 的锚点规则统一保证，本文件不重复定义锚点。
