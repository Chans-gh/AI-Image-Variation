# 方向规则：用途拓展（`usage`）

**规则版本**：1.0　|　**注册表版本**：1.0　|　**状态**：`active`　|　**支持模式**：grid、sequence
**默认分支**：`variants`（离散变体）　|　**可选分支**：`variants`（离散变体）、`progression`（渐进演变）、`narrative`（情节叙事）

> 本文件由 `tests/build_direction_docs.py` 从 `registry.json` 生成，请勿手改；规则变更改注册表后重跑脚本。

## 允许变化（allowed_changes）

- 画面用途取向：封面感、主图感、详情页感、海报留白感
- 留白位置与面积（为文字预留安全区）
- 视觉中心与视线落点
- 构图适配目标版式（方形、竖版、横版）
- 主体占比与信息密度

## 必须保持（must_preserve）

- 主体身份与内容完整
- 品牌感与整体调性
- 关键产品结构不被裁切
- 画面质量与色彩准确性

## 禁止项（avoid）

- 生成具体文案、Logo 文字、UI 控件或价格标签
- 把留白做成大面积空白导致主体过小
- 声称适配某平台官方规格（需实测）

## 变化示例（variation_examples）

- 同一产品：居中主图、左上留白封面、竖版海报式、方形详情主图
- 同一人物：杂志封面留白、商品主图、宣传海报、社交方图
- 同一道菜：菜单主图、海报留白、外卖图、方版封面

## Grid 规则

- 行优先映射：是
- 零间距零边框：是
- Grid 不表达时间/因果顺序：是
- 格位提示：每格一种用途取向；不得在格内叠加文字或图形元素

## Sequence 规则

- 张数范围：4–16 张
- 渐进轴提示：留白比例由满构图到极简留白的渐进
- 叙事分支需要世界观上下文：否

## 与其他方向的边界

- 本方向只改变上表「允许变化」中的元素；出现 `must_preserve` 被改动，或落入 `avoid`，即判为该张不通过。
- 一个任务只能选择一个方向。若用户表达同时命中两个方向（例如"换场景同时换天气"），先请用户确认优先级，不自动混用。
- 主体一致性由 SPEC 01 §6 的锚点规则统一保证，本文件不重复定义锚点。
