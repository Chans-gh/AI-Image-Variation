# 方向规则：视角拓展（`view`）

**规则版本**：1.0　|　**注册表版本**：1.0　|　**状态**：`active`　|　**支持模式**：grid、sequence
**默认分支**：`variants`（离散变体）　|　**可选分支**：`variants`（离散变体）、`progression`（渐进演变）、`narrative`（情节叙事）

> 本文件由 `tests/build_direction_docs.py` 从 `registry.json` 生成，请勿手改；规则变更改注册表后重跑脚本。

## 允许变化（allowed_changes）

- 水平机位：正面、四分之三侧、侧面、背面
- 垂直机位：平视、略俯、大俯、仰视
- 景别：特写、近景、中景、全景
- 摄影机距离与主体占比
- 视线引导方向

## 必须保持（must_preserve）

- 主体身份与服饰/结构细节
- 场景地点与陈设
- 光照方向与时间感
- 色彩与美术风格

## 禁止项（avoid）

- 通过换视角偷偷更换场景或造型
- 极端畸变导致主体结构变形
- 同一任务内混入 style 或 light 的变化

## 变化示例（variation_examples）

- 同一张长椅：正面全景、侧面中景、俯视、仰视
- 同一只手办：正面、四分之三、背面、俯拍特写
- 同一间书房：门口全景、书桌近景、窗边侧拍、俯视布局

## Grid 规则

- 行优先映射：是
- 零间距零边框：是
- Grid 不表达时间/因果顺序：是
- 格位提示：格位之间只体现机位差异，不按时间排序

## Sequence 规则

- 张数范围：4–16 张
- 渐进轴提示：机位角度渐变或环绕（如每帧转 45°）
- 叙事分支需要世界观上下文：否

## 与其他方向的边界

- 本方向只改变上表「允许变化」中的元素；出现 `must_preserve` 被改动，或落入 `avoid`，即判为该张不通过。
- 一个任务只能选择一个方向。若用户表达同时命中两个方向（例如"换场景同时换天气"），先请用户确认优先级，不自动混用。
- 主体一致性由 SPEC 01 §6 的锚点规则统一保证，本文件不重复定义锚点。
