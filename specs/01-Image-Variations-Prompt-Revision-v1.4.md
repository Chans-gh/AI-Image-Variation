# SPEC 01 提示词修订 v1.4

本修订覆盖 v1.3 的五条方向规则和相关规划与审核模板。方向键、名称、Grid 画幅、Sequence 分支和尺寸执行继续使用 v1.3 的契约。其他模板沿用基线。新增的计划证据字段只适用于本次修订的方向。

### directions/view.txt

```text
主变化方向：围绕同一主体重新摆放相机，重建每格可见表面和投影。以主体自身的正面、左右、背面及地面为坐标，按这个坐标描述水平位置与镜头高度。

起点和参考使用：从参考图提取身份、服饰配件、站姿或物体朝向，以及场景特征。原图中的相机位置、二维轮廓、对镜回眸和入画边界不是新机位的锚点。固定身体在场景中的朝向与基础姿态，允许头和眼睛呈现新机位下自然可见的方向。背面只显示背面可见的结构，隐藏的五官不需要露出来证明身份。

规划方式：先列分离明确的相机位置，再从该位置反推相机应看见与不应看见的部位、遮挡和远近。未限定机位的 2×2，优先覆盖正前平视、近 90° 的侧向、正后平视、明显高位俯拍这四类。更多格扩展环绕位置与高度，可配合取景范围；每格仍需一个独立机位证据。用户明确指定的角度优先。声音、文字标签和 EXIF 数值不能作为视觉证据。

参考图有可辨环境时，先锁定主体脚印及面朝的固定环境方位，再推导不同机位背后是场景的哪一侧，以及哪些地标会横移、遮挡或退出画面。例：人物朝林荫路深处站立，从正面拍时身后应看到来路一侧；从背面拍时身后应看到去路；纯侧应横看路径。不要用同一背景的消失点、同一棵树的同一投影加转身的人物冒充机位变化。保持同一场地和地标关系，重建各个机位可见的那一面。纯色棚景或无空间线索时，写明背景的适用限制，再用主体的表面、结构和遮挡检验。

可见判据：人物正面可见胸前与双肩，侧面只见一侧轮廓和远侧遮挡，背面可见背部及后脑，俯拍可见头顶及地面，身体纵向缩短。产品用正背部面板、接口遮挡和顶面判断；空间用墙面夹角、入口或固定地标的遮挡和视差判断。放大、裁切、让主体重复向镜头回头不足以形成新机位。

必须保持：主体身份、基础姿态或物体朝向、核心结构、主体造型、同一空间、光照状态与画面风格。允许可信重建参考图未显示的表面，保持物体结构和空间线索一致。

逐格或逐帧 direction_evidence 必须填写 camera_position（相对主体的机位和高度）、visible_projection（新机位造成的主体可见表面、遮挡或几何证据）、world_projection（同一个环境从该机位的可见方向及地标关系，或背景无对应线索的说明）。审核主体与环境的实际投影；如果都是同一个三分之四轮廓，或可辨场景只改变主体朝向而背景投影不动，指出冲突格并判视角证据不足。

Grid 输出 {{ITEM_COUNT}} 个独立画格，按行优先组成一张零缝整板。Sequence 输出 {{ITEM_COUNT}} 张独立图片并遵循 {{BRANCH}}，有序分支可沿一条连续且不回退的机位轴推进，仍需每帧可辨。
```

### directions/scene.txt

```text
主变化方向：从参考图或文字中的已有环境出发，向同一视觉世界的相关空间发散。优先让读者看到主体从哪里来到哪里，以及相邻地点为什么相连。

先定位出发点：读清已存在的道路、入口、材质、绿化、建筑轮廓、展示台或动线。为整组建立一条可画出的空间联系，例如林荫步道→穿过入口→进入相连的花园→从出口抵达街口；室内可从门厅经廊道抵达房间和户外。纯文本用描述中的地点作出发点，缺省地点补出一个可信空间。以可见的门框、道路拐点、栏杆、台阶、连通的材质或共同地标，把相邻画格接起来。只有色调相似不足以证明空间连续。

让每个地点有独立功能和具体变化。换点时至少出现一个新的主要空间特征，并带出与前一地点的可见联系。可按行优先表达抵达、经过、离开等空间前后感；每幅图本身完整。主体正在沿可信路径行进时，允许步态、朝向或视线随地形变化。产品和物件可用相邻的陈列、取用和使用区域表现同一个空间系统；建筑和空间主题可从公共区到内部再到相连的室外。若用户明确要求独立地点，围绕同一个出发设定与实际用途建立关系，避免虚构它们在物理上相邻。

必须保持：核心身份、关键外形或衣着、同一世界观、摄影风格及时间逻辑。场景可以明显改变；不过度锁死原图背景和原姿态。避免换地点同时换造型、突然跨季节、用戏剧事件替代空间差异，或把同一个背景换四种轻滤镜。

逐格或逐帧 direction_evidence 必须填写 place（本幅的可识别地点和功能）、route_connection（与出发点、前一地点或相邻出口的关系）、visible_landmark（在画面哪里能看到连接证据）。第一幅写清出发点和下一处的视觉指向，后续各幅在实际画面交接；审核时能看出地点差别和关系。若两处有高差，预先锁定跨越方向，核对相邻两格中门、台阶、地面材质的前后位置和高低一致。没有高差需求时用同一门槛、铺面接缝或地标连接平层，减少不必要的空间歧义。人物的步态与视线应能对应即将抵达的位置，避免各格机械复用同一回眸。

Grid 输出 {{ITEM_COUNT}} 个独立画格，按行优先阅读地理路线或关联空间，整板零缝。Sequence 输出 {{ITEM_COUNT}} 张独立图片并遵循 {{BRANCH}}。variants 可展示从同一参考地点辐射的关联空间；有序分支保留进出顺序与每帧承担的主变化。
```

### directions/weather.txt

```text
主变化方向：同一主体在不同天气、季节或时间条件下合理存在。天气要同时影响环境和该主体的处境、行为、服装层或使用方式。根据条件强度选取合适反应。

先明确因果。每幅写出天气或时间条件、其对地表和能见度等的可见影响，以及它对主体的直接影响或合理应对。人物在露天持续下雨时持伞、穿雨衣或躲到可见遮蔽处；伞被实际握持且挡住落雨范围，路面湿润，遮蔽内外降雨一致。寒冷或积雪下用适当外层、防滑鞋、缩身动作或其他可信御寒证据。强风让衣摆、发梢及周围枝叶方向一致；雾由远景逐渐被遮挡表现，可伴随放慢脚步或低能见度下的可见行为。普通晴日、轻雾或昼夜变化按实际需要决定动作和服装，避免无因添加雨具或厚衣。

动物可避雨、寻荫或有可见的受风变化。产品可在天气防护下使用，或呈现与材质、位置相符的水滴、结霜和保护状态；不凭空声称防水。固定建筑的响应可以是灯光启停、遮棚、积水或人流方式的变化。明确处于室内时，说明环境隔离方式和视野中的天气证据，人不必做户外防护动作。

必须保持：核心身份、辨识点、场地结构、共享地标和视觉风格。允许符合该条件的外穿层、伞、鞋、站位及动作变化，保留能认出的基础造型。用户明确锁定穿搭时，选择遮挡、躲避、动作等兼容做法。动作和穿搭变化服务于天气，应能解释为什么此时需要它。

逐格或逐帧 direction_evidence 必须填写 condition（具体天气、强度或时间）、environment_effect（地表、降落物、天空、空气或人流等可见证据）、subject_response（行为、防护、状态或隔离怎么因环境变化）。避免把同一人物姿态和服装原样贴到每种环境，或仅凭色温命名。审核人与环境的因果，尤其检查雨中露天、防护有效性和寒冷应对。

Grid 输出 {{ITEM_COUNT}} 个独立画格，时态可以各自成立，整板零缝。Sequence 输出 {{ITEM_COUNT}} 张独立图片并遵循 {{BRANCH}}，有序分支保留地面从干到湿、天气变化后尚未散去等合理的延续。
```

### directions/lens.txt

```text
主变化方向：通过拍摄距离和取景范围拓展镜头语言。用户没有另指定拍法时，以景别为主变量。先确定画格里能看到多少主体、主体占画面多少、哪里出画，再设计镜头。保持主体身份、核心造型或产品结构、同一场地和时间光线、同一整体美术风格。景别对照可沿同一拍摄方向推进，参考图的原始大小和入画边界由每镜重新选择。

未限定景别的人物 2×2 按从远到近做四镜，逐格重新取景：
1. 大远景交代空间。人物从头到脚约占格高 15%–25%；步道走向、植被或建筑的整体关系占画面主体。
2. 全身看完整人物与造型。头顶、两只鞋、衣服和随身配件完整可见，人物约占格高 65%–85%；脚下保有少量地面。
3. 中近景看上半身和表情。头部与双肩完整，框的下缘在胸口至腰上方，腿和鞋出画；上身与场地留少量呼吸空间。
4. 特写看面部。脸从额头到下巴占据画格大部分高度，眼鼻口能读清，身体与大部分肩部出画，只在边缘透露现场背景。

同样的跨度可用于产品和空间，例如从环境中的设备到完整设备、包含多个相连部件的近景，再到一个关键结构特写。用户指定景别或拍法时优先达成其取景要求，包括只对比光学表现的任务。大网格或长序列可进一步使用远景、膝上、头肩等中间景别。常用景别用完后，同一档景别内可用明确可辨的焦平面、前景观察方式或运动成像扩展，取景区别应能从图上验证。

逐格或逐帧 direction_evidence 必须填写 framing（主体占比、哪部分入画、边界在哪）、capture_method（机位距离、取景或用户指定的成像机制）、visible_effect（缩略图上一眼可定位的证据）。distinctive_cue 指出和最相似一镜直接可比较的区别。审核时先看未标注的实际整板，按主体大小和取景边界读出每格景别，再与计划核对。计划中的景别缺失，或预期不同景别的两格只差轻微虚化和背景时，点名格号并判差异不足。计划内有意使用相同景别时，核对实际可见的光学或取景区别。

Grid 输出 {{ITEM_COUNT}} 个独立画格，整板零缝。Sequence 输出 {{ITEM_COUNT}} 张独立图片并遵循 {{BRANCH}}。渐进可沿景别由远到近推进，叙事可按信息顺序组合景别；每一张都要有可指出的取景区别。
```

### directions/usage.txt

```text
主变化方向：从可交付的明确用途出发，重新组织同一主体需要传达的信息。每幅先回答给谁、放在哪里、看完要认出什么、经过实际裁切或排版还能不能用。

先用用户给出的目标平台、成品和版位。若未给出，选择与主体匹配、功能确实不同的成品，避免套用四个空泛的平台名。人物可以做圆形裁切可识别的个人头像、全身穿搭图集首图、保留有意义环境的采访横裁底图、留出标题安全区的竖屏主题封面。产品可用能立刻辨认完整外形的商品主图、读得清用法的详情配图、展示真实安装位置的场景底图。空间可用能识别入口的导览开篇、展示路线逻辑的辅助图、有标题安全区的活动底图。用途不同应导致主体信息、景别或承载位置的具体变化。用户只指定一种成品时，在该成品内设计功能或版位不同且确实可用的版本。

版位约束落成可检查的画面条件。头像需要中心裁切后保住眼睛、下巴和辨识特征；穿搭首图的鞋、配件和外轮廓要完整；横裁底图要在同一原始画幅的中央裁切带保住脸和场景地标；标题封面需留出一块连续、低干扰且能放文字的明确区域。废弃只写「海报感」「左留白」或「头像风格」的计划。质量检查实际对齐裁切框或文案区，在图片之外审查。保持原布置的核心风格与身份，可按版位选择景别、弱化干扰背景或调整主体位置。

Grid 和 Sequence 均服从同一次任务的目标画幅，几种用途的目标裁切区可以位于原画幅内。不要在原画幅内绘制模拟界面、卡片、分隔框、文字、标记、角标或按钮。若用户指定的最终资产需要不同原生画幅，按画幅分组分开生成；不要把模拟异形画框误报为完成的原生交付物。

逐格或逐帧 direction_evidence 必须填写 deliverable（实际成品及版位）、communication_goal（目标观看者必须读到的信息）、placement_or_crop（裁切或排版区域，以及应保留的信息）、acceptance_test（实际验收操作与合格条件）。若两个方案只改主体位置，代入任务裁切或排版后仍没有清楚的功能差异，应重做用途计划。

Grid 输出 {{ITEM_COUNT}} 张可独立使用的源素材，按行优先组成一张零缝整板。Sequence 按 {{BRANCH}} 输出 {{ITEM_COUNT}} 张独立素材，分支的顺序不能替代用途验收。
```
