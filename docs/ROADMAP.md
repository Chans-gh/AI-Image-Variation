## 联调时要解决的版本及平台事项

- **01 → 02 契约衔接。** 现有共享层已能按 schema 读取 1.0 / 1.1 及导出只读选图视图。02 仍需把旧 `tile_edge_ok`、`seam_score` 的预检与 01 v1.3 的 `dimension_execution` 对齐。旧证据缺失时记录 `validation_unverified`，保留原始版本和哈希。用户选择后才创建内容任务。
- **平台规格与编辑器。** SPEC 中的公众号宽幅 `2.35:1` 和方形 `1:1` 是待验证预设。实测封面尺寸、HTML 导入、小红书字符和图片数量、话题及披露规则，再回填配置。当前规划交付可用素材包，平台账号发布需要明确授权。
- **尚未确定的产品项。** Skill 02 正式名称、目标宿主和研究工具、批量预算上限、是否提供其他素材导入入口，见 SPEC 02 §15。 [SPEC 02](../specs/02-Image-Content-Publishing-Skill-v1.1.md#15-未确认事项与建议默认)
